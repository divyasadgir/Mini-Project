
# Library Management Platform
## Unit 1 – Mini Project

### 1. Introduction
The Library Management Platform is designed to automate library operations and improve the experience of students, faculty, and librarians.

### 2. Problem Statement
Manual library management causes delays in book searching, issuing, returning, and fine calculation.

### 3. Project Objectives
- Easy book search and availability.
- Student and faculty management.
- Book issue and return management.
- Automated fine calculation.
- Administrative reporting.

### 4. Design Thinking
1. Empathize
2. Define
3. Ideate
4. Prototype
5. Test

### 5. Main Features
- User Login
- Book Catalog Management
- Issue and Return Management
- Fine Management
- Notifications
- Admin Dashboard

### 6. Technology and Engineering Roadmap
- Application Development
- Database Management
- Docker
- Kubernetes
- Terraform
- Ansible
- CI/CD

### 7. Conclusion
This project aims to provide an efficient, automated, and user-friendly Library Management Platform.
